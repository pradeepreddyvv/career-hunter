Installation

1
Install Tampermonkey

Get it from tampermonkey.net for Chrome, Firefox, Edge, or Safari.

2
Install the userscript

Click the Install Userscript button above. Tampermonkey will detect the script and show an install prompt. Click "Install".

3
Configure your Gemini API key

Click the Tampermonkey icon in your browser toolbar → "Career Hunter — LeetCode Companion" → Configure Career Hunter. Enter your free Gemini API key.

4
Open any LeetCode problem

Navigate to leetcode.com/problems/* or neetcode.io/solutions/*. You'll see the companion toolbar at the bottom-right.

How It Works

On LeetCode

The companion reads your code from the Monaco editor and the problem description. As you code, click quick-action buttons or use voice to talk with the AI interviewer. It sees your code in real-time and gives contextual feedback.

On NeetCode

The AI becomes an explanation interviewer. It reads all solution approaches on the page and tests whether you truly understand them. Walk through each approach out loud — the AI probes with follow-up questions just like a real interview.

Live Listen Mode

Click Live for hands-free mode. The AI listens continuously and interrupts naturally when you pause, ask a question, or need a nudge. It decides on its own when to speak vs stay silent.

Voice Controls

  • Mic button — Click-to-talk: hold to speak, release to send
  • Live button — Continuous listening with AI-driven interruptions
  • Talk Now — Force the AI to respond to your current transcript
  • Ctrl+Shift+M — Keyboard shortcut for quick voice

Configuration

All settings are managed through the Tampermonkey menu (click Tampermonkey icon → script name → Configure):

  • Gemini API Key Required — Free from AI Studio. Powers all AI features.
  • Career Hunter API URL — Webhook URL for code sync (default: localhost:3000). Optional.
  • Speechmatics TTS Key — Optional, for high-quality voice. Falls back to browser TTS if not set.

Supported Sites

✓ leetcode.com/problems/* — Full code capture + AI coaching
✓ neetcode.io/solutions/* — Solution explanation practice

No data is sent to any server. All AI calls go directly from your browser to Gemini using your own API key.
